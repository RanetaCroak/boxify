# Boxify

Aplicación personal de gestión de inventario pensado para un uso doméstico, y llevar un seguimiento de garantías y otros datos.

## Objetivo

Organizar el inventario de casa y trasteros para facilitar su búsqueda, datos de garantías, y problemas de mudanza.
Garanizar un uso en formato web, app móvil y la habilidad de compartir datos entre usuarios y sincronización offline/online.

## Tecnologías

- Java
- Maven

## Estado del proyecto

En desarrollo. Actualmente se encuentra en una fase inicial de aprendizaje y construcción.
